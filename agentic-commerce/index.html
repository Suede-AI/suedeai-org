Agentic Commerce

ACP and x402 let agents pay per call.

Suede Labs runs three paid generation resources on Base mainnet and a hireable ACP agent for music and video generation.

By Jason Colapietro (Johnny Suede) · Founder & CEO of Suede Labs AI

The payment layer for agent APIs

The Agent Commerce Protocol (ACP) describes what a hireable agent can do. x402 is the HTTP-native settlement layer that lets a client pay per call in stablecoins without an account, API key, or human checkout flow.

Suede Labs uses those rails for generation resources that can be verified directly through public well-known files.

What Suede already runs in production

3 paid x402 resources on Base mainnet. Music generation, video generation, and image generation are priced per call in USDC and discoverable through standard well-known files. The Producer by Suede Labs agent is registered as a hireable Virtuals ACP agent for music and video generation and ACP/x402 consulting.

  • x402 discovery: app.suedeai.ai/.well-known/x402.json
  • Agent card (ACP): app.suedeai.ai/.well-known/agent-card.json
  • Agentic commerce manifest: app.suedeai.ai/.well-known/agentic-commerce.json
  • Virtuals ACP profile: app.suedeai.ai/.well-known/virtuals-acp.json
  • Producer agent ID: 019e3991-374d-75f3-a6b8-17ff309b4cd2

What the current evidence supports

Agent-driven traffic needs resource discovery, machine-readable pricing, and reliable settlement. Suede exposes those pieces for music, video, and image generation. The IP Registry and related rights workflows remain paused during security remediation and are not part of this production claim.
