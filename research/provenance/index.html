Provenance research

Creative provenance connects an exact file to its recorded history and the claims made about it. The useful design problem is keeping those records understandable as the work changes hands and versions.

By Jason Colapietro (Johnny Suede) · Founder & CEO of Suede AI

Begin with the exact file

A fingerprint identifies a particular sequence of bytes. If a musician re-exports a recording, changes embedded metadata or produces a different mix, the resulting file may have a different fingerprint. Keep the original export and identify later versions deliberately. The practical question is not only whether a file has a record, but whether the record you are looking at belongs to the file you actually received.

Keep claims distinct from the file history

A provenance record can state who submitted a claim, which file it refers to and when the record was made. Contributor descriptions and permission documents add context. Keep those assertions identifiable so a reader can distinguish an observed file match from a statement supplied by a participant. This makes a record easier to review when information is corrected or two parties describe the same work differently.

Follow one work through several versions

Consider a demo, a final master and an instrumental export. Give each file a clear name, preserve the corresponding fingerprint where one has been recorded, and document the relationship between versions. A collaborator should be able to identify which version a credit, approval or delivery note refers to. A lineage record is useful when it makes that relationship inspectable; it should not silently transfer assumptions from one file to another.

Preserve a usable handoff

A practical handoff contains the exact delivered file, credits, the relevant record link and the agreements needed for the intended use. Store the files and supporting documents together, with private material shared through the appropriate channel. The recipient should be able to answer three questions: is this the expected file, where did the attached claims come from, and which document describes the intended use?
